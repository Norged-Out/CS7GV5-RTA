\section*{Overview}

This project is built around three motion-editing demos in Unreal Engine, each covering a different part of the animation pipeline. The first focuses on retargeting the same walking clip onto three MetaHumans with different proportions, the second develops a two-character Rock-Paper-Scissors interaction system, and the third looks at facial performance transfer using Live Link and MetaHuman Performance assets with clips from the RAVDESS dataset. Even though the demos are quite different from each other, they all point back to the same basic issue: source animation is rarely strong enough to use as-is.
